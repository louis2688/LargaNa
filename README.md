# LargaNa

LargaNa is a ride-hailing product for the Philippines, with a responsive Next.js rider experience and an Expo-powered mobile app for iOS and Android.

## Run the web app

```bash
pnpm install
pnpm dev:web
```

Open `http://localhost:3000`.

## Run mobile

```bash
pnpm dev:mobile
```

Scan the Expo QR code with Expo Go or launch an iOS/Android simulator.
